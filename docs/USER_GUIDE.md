# RIME 配置小工具用户说明

## 开始使用

首次打开后，在“设置”中确认 Rime 用户目录。程序会自动寻找常见的小狼毫目录；未识别时可手动选择。目录有效后，可在同一页面检查本工具管理的文件并执行“立即重新部署”。

主界面左侧分为六个职责清晰的工作区：

- **词库工作台**：维护个人词条、分组、权重和候选顺序。
- **词典中心**：按当前输入方案浏览系统词典、扩展词库与用户词典。
- **词库维护**：集中放置重码、检查、自动分组、跨方案导入和历史等低频工具。
- **输入习惯**：可视化维护全拼候选数量、翻页键和中英文切换键。
- **符号管理**：维护 `symbols_v.yaml` 的分类和符号候选。
- **设置**：管理 Rime 环境、词典文件、备份、诊断、更新与主题。

左下角会持续显示 Rime 连接状态；索引构建等后台任务会在主窗口底部显示阶段和进度，不需要停留在某个页面等待。

## 词库工作台

词库工作台跟随当前 Rime 方案：白霜维护 `custom_phrase.txt`，万象维护 `wanxiang_user_phrase.txt`。顶部命令栏可搜索文本或编码、筛选和排序；左侧按分组浏览，右侧表格维护词条。双击文本或编码可打开编辑窗口，同一文本可保存多个编码。

“+ 新增词条”和“快速调节”是日常高频入口；导入、重码、修改历史和自动分组统一放在左侧“词库维护”。内联编辑与分组修改先暂存在当前窗口，底部出现未保存提示后，点击“保存修改”才会统一写盘并按设置部署；“撤销”会放弃本轮暂存修改。删除分组可直接删除、先备份当前方案词库后删除或取消；只移除分组关系，词条保留为未分组。

点击“快速调节”会打开独立窗口。窗口只保留一个精确查找入口，可输入完整字词或完整拼音编码；查找范围包含个人、系统/白霜及万象静态词典，不进行无边界子串匹配。程序也支持明确的单字母首码、严格简拼、紧凑简拼和混剪简拼，例如 `h` 可反查单字首码候选，`wut`、`wti` 均可反查“物体”。修改搜索条件或开始输入法预编辑时会立即清除旧选择，避免显示上一轮结果。

从结果表选择词条后，下方“当前调节项”只读显示该词条和编码，避免字词、编码两个输入入口互相覆盖。实际输入法候选由当前启用方案的隔离 Rime 会话读取，并遵循当前 Rime 的每页候选数；万象不会再用白霜候选或静态词典排序代替实际结果。置顶、上移、下移只在窗口内暂存；点击“保存”后，程序才会统一备份、写入当前方案的个人词库并按设置部署。直接关闭窗口会放弃未保存修改。系统词条保存时会成为当前方案的个人覆盖项，不会改写原始固定词典。

索引首次建立或后台更新时，主窗口标题栏和底部状态区会显示当前文件与进度；此时打开“快速调节”也会明确提示仅能显示已就绪的数据。可取消本次构建，旧的可用索引不会被替换；之后可从同一位置重试。

页面顶部会在同一行显示当前启用的拼音方案、本页实际编辑的词库文件和识别依据。程序低频监视 Rime 的小型状态文件；手动热切换方案后自动更新工作台、备份、设置和相关页面。多方案状态无法确认时关键写入保持只读，不会猜测并写入白霜。

“批量选择”开启后，可点击行、勾选框或拖拽连续选择，再执行批量删除或调整分组。完成操作后程序会退出批量选择状态。

## 词典中心

词典中心只显示当前输入方案实际使用的词典，不会在使用万象时混入白霜词典。上方列表展示词典名称、原文件名、用途和类型；选择词典后，下方可按完整字词或完整拼音编码精确筛选词条。

固定系统词典保持只读，可选择词条后进入快速调节并创建个人覆盖项。对于程序确认可安全直接维护的单文件个人词典，可在表格内暂存新增、删除或编辑，点击“保存”后才会备份并写回；切换词典或关闭前若有未保存内容，程序会要求确认。

## 在白霜与万象之间导入个人词库

在“词库维护”点击“跨方案导入”，程序以当前正在使用的方案作为接收目标，可在白霜 `custom_phrase.txt` 与万象 `wanxiang_user_phrase.txt` 之间双向复制缺少的词条。此功能只处理 Tab 分隔的全拼自定义短语，不处理双拼方案、`.dict.yaml` 固定词典或 Rime UserDB。

### 操作步骤

1. 保存或撤销词库工作台尚未保存的修改。
2. 先在 Rime 中切换到要接收词条的方案，再点击“跨方案导入”。窗口会明确显示来源和目标，并分别统计来源总数、目标将新增、目标已有并跳过和需确认的新增项。同词同码但内容不同的项目可点击“逐项处理已有差异”，默认保留目标，也可明确选择采用来源。
3. 如果显示“需要确认”，阅读通俗提示并勾选确认；程序会保留这些内容的原样。此时“开始导入”仍可点击，如果尚未勾选，程序会明确指出需要确认的位置，不会写入文件。
4. 点击“开始导入”，等待完成提示。

一般使用时无需阅读文件路径和检查步骤。需要排查问题时，可展开“详细信息（排查问题时使用）”查看。

### 无损与安全边界

- 来源文件始终只读，导入前后会以 SHA-256 验证未被本工具改动。
- 两套方案继续使用各自独立的个人词库；首次导入到万象时才安全确认 `wanxiang.custom.yaml` 的挂载，不让两套方案长期共用同一文件。
- 预览会区分完全重复与“同词同码但排序值或格式不同”；后者默认保留目标方案现有内容，不静默覆盖。
- 编码中的撇号、两列词条、缺省权重、特殊权重、BOM、换行风格和来源顺序不会经过普通编辑器的归一化。
- 提交前会重新检查来源、目标、万象配置和方案文件是否被外部修改；发生变化时要求重新扫描。
- 写入前创建不参与轮转的迁移快照；部署或验证失败时恢复旧文件，新建目标文件也会删除。

如果 `wanxiang.custom.yaml` 已经挂载其他自定义词库，向导只报告冲突，不会静默覆盖。CSV、UTF-16、固定词典和含无法识别行的来源会被拒绝，不提供“跳过错误继续”选项。

沙盒模式可查看导入预览，但不能执行真实迁移。导入报告只显示数量和风险类别，不显示词条文本。

## 采集与候选预览

使用设置的全局热键采集当前已选中的文本。采集窗口会给出全拼及简拼建议，并按当前 Rime 的 `menu/page_size` 显示当前启用方案的独立 Rime 会话候选和可读取的权重信息。候选预览仅用于辅助判断，不会改变正在使用的输入法。

启用万象拼音时，程序会在 `%LOCALAPPDATA%/RimeConfig/preview` 下准备隔离副本，并只在该副本中启动预览会话；不会把真实 Rime 用户目录作为预览写入目录。若个别正在使用的 UserDB 无法复制，界面会如实提示本次预览可能缺少对应的动态候选。

纯英文文本可选择小写、大写或原样编码；英文短语的空格和连字符会自动移除。

## 分组、重码与历史

分组侧栏显示各组条目数。点击“显示重码字符/文本”可按同文本多编码或同编码多文本查看；双击项目后可集中编辑，点击“保存全部”才写入词库。

“修改历史”可查看词库维护记录。v0.9.1 起新产生且带完整写前快照的记录可回滚；程序会先备份当前版本，旧记录或已轮转的快照只读显示。词库检查可发现空值、重复项、权重或分组问题。“部署状态”可查看当前部署任务、最近结果并手动重新部署。

搜索、分组、快速筛选和排序组合可从工作台的“常用筛选”保存。筛选按当前输入方案隔离；应用筛选时如原分组已删除，会安全回到“全部”。

## 输入习惯

“输入习惯”只提供全拼且能够按名称安全映射的设置。每页候选数量、`[ ]`、`- =`、`, .` 三组翻页键可以同时配置；空格继续提交当前高亮候选，可选用分号/单引号上屏第 2/3 项，不提供裸左/右 Ctrl 选词。修改先保留在页面，白霜保存到 `rime_frost.custom.yaml`，万象保存到 `wanxiang.custom.yaml`，不会改写方案原文件。万象页还可设置用户词频、整句、上下文建议、英文空格与候选数量、反查声调；随版本变化的 Lua、模糊音和过滤链仍由适配预检保护。

候选窗外观编辑功能当前已从程序中剔除；已有冻结源码与用户配置仍保留，但程序不再提供该页面或写入入口。

## 备份与恢复

每次关键保存前会备份本工具管理的当前方案文件。白霜和万象使用独立备份、保留份数与最近备份时间；切换方案后只显示并管理当前方案的备份。设置页可立即备份、启用定期备份、设定保留份数和自动清理，并直接打开备份文件夹。

恢复时先选择受管文件和对应备份版本。可先点击“恢复前比较”查看将加入和移除的行，再点击“恢复所选备份”；恢复前程序会先备份当前文件。

## 托盘、部署与更新

关闭窗口或在主窗口按 Esc 后，程序仍驻留系统托盘。托盘菜单可显示主窗口、立即重新部署、切换保存后自动部署和开机自启。

“检查更新”会自动识别当前运行的是单文件 `RimeConfig.exe` 还是目录式便携包：前者只下载并替换 EXE，后者只下载 `RimeConfig-portable.zip` 并整体替换程序目录。更新失败会自动恢复旧版本。

程序每天在后台低频检查万象拼音更新。版本号只用于提示：新版会先下载到隔离缓存，检查 Base 包来源、目录、全拼关键文件以及本工具使用的配置能力。已登记版本可按设置自动更新；未登记但检查通过的版本会请用户确认后谨慎更新；检查失败才显示等待适配。更新前建立与日常备份分开的万象恢复备份，个人词库、UserDB 和 `*.custom.yaml` 不会被更新包覆盖，重新部署失败会自动恢复。若官方文件曾被本地修改，普通更新停止并显示“强制更新”；强制更新仍不能绕过来源和能力检查。设置页可查看并恢复最近一次更新前版本，下一次更新部署成功后自动轮换旧恢复备份。

输入诊断默认不运行。需要排查候选窗或按键异常时，在“设置”页点击“启动输入诊断”，程序会单独启动 `RimeInputDiagnostics.exe`；关闭诊断窗口后监控立即停止。

## 主题与数据位置

程序提供浅色、深色和水墨三种主题。程序设置、历史和缓存保存在当前 Windows 用户的应用配置目录；发布版默认备份目录位于“用户文档\RIME 配置小工具\Backups”。

本地发布包未进行商业代码签名，Windows SmartScreen 或杀毒软件可能在新版本首次运行时要求确认。请只使用本项目生成或官方发布页提供的文件；如出现提示，可先核对文件来源和校验值，不要从不明来源添加排除项。
