# 本地发布记录

## v0.9.1 - 2026-08-10（源码开发版）

- 候选窗外观已从主导航和运行时页面中剔除；冻结源码、测试及已有用户配置兼容继续保留。

### 性能与资源占用

- 词典中心的递归目录扫描移出 GUI 线程，进入页面后先显示明确加载状态；同一页面会缓存各方案目录，重复切换不再重复解析。
- 主选项卡切换改为可取消的按需激活，快速连续切换不会继续执行已经过期的页面加载任务。
- 目录加载轮询仅在后台任务存在时运行，完成或页面销毁立即停止；词典行批量填充期间暂停绘制和选择信号，减少无效重排。
- 测试窗口关闭时统一停止定时器、监视器和后台服务，消除跨用例资源累积导致的整套测试逐渐变慢。
- 保持既有单一数据引擎与合并部署任务，不新增常驻进程、索引副本、框架或生产依赖。

### 全局采集

- 热键触发后先等待修饰键释放；Windows 标准编辑框直接读取选区、不改剪贴板也不发送复制键，其他程序再走安全剪贴板路径。若前台窗口已经变化则安全终止，不强制附加其他程序的输入线程或抢占焦点。
- 采集窗口取消 5 秒倒计时自动保存，必须由用户确认收藏；保存成功后右下角通知保留 5 秒关闭倒计时。
- 新增编码输入恢复为可编辑状态，并继续执行编码格式校验和候选建议。

### 恢复、历史与部署

- 设置页可在恢复前比较当前文件与所选备份，显示即将加入和移除的内容；大差异仅展示前 2000 行，避免预览本身消耗过多内存。
- 新产生的修改历史记录关联写前备份快照；可一键回滚整组可验证文件。回滚先读取目标快照、再备份当前版本，并通过多文件事务提交，失败不会留下半套文件。
- 旧历史没有快照时保持只读，不提供不可靠回滚；已被备份轮转或移动的快照会拒绝恢复。
- 词库维护新增部署状态窗口，显示当前任务、合并补跑状态和最近 30 条部署结果，并提供手动重新部署入口。

### 导入与工作台

- 跨方案导入对同词同码但排序值或行格式不同的项目提供逐项选择；默认保留目标内容，只有明确选择后才采用来源内容。
- 冲突替换保留目标文件中的原行位置，继续执行来源指纹复检、事务快照、部署验证与失败恢复。
- 常用筛选按输入方案保存，可同时恢复搜索词、分组、快速筛选和排序；已删除分组自动回退到“全部”。

### 范围与风险

- 候选窗皮肤编辑继续冻结，遗留问题记录仍以 `docs/SKIN_EDITOR_BACKLOG.md` 为准。
- 不删除生产已停用的旧索引代码，不执行 PyInstaller，不生成或覆盖发布包。
- 本版本没有引入新的 Skill、Agent Runtime、UI 框架、常驻服务或第三方生产依赖。

### 验证

- 采集、万象导入与窗口生命周期聚焦回归：52 项通过；完整回归：`315 passed, 1 skipped`，退出码 0。
- 完整回归单进程用时 26.68 秒；原先测试对象未充分释放造成的累计变慢已修复。
- 源码 GUI 已成功启动并保持响应；空闲稳定采样工作集约 211 MB、私有内存约 132 MB。
- 未执行 PyInstaller；以上结果不等同于发布包或干净机器验收。

## 当前开发版（未打包）

- 当前 Rime 方案成为个人词库、设置、备份、索引与写入保护的统一来源；白霜写入 `custom_phrase.txt`，万象写入 `wanxiang_user_phrase.txt`，状态不确定时保持只读。
- 主导航拆分为词库工作台、词典中心、词库维护、输入习惯、候选窗外观、符号管理和设置；低频维护工具不再挤占日常工作台。
- 新增全拼输入习惯与小狼毫候选窗外观的安全可视化补丁页，只写 `.custom.yaml`，不迁移 QML/Qt Quick。
- 输入习惯支持三组翻页键并存和分号/单引号选择第 2/3 项，取消裸左/右 Ctrl 选词；万象页提供用户词频、整句、上下文建议、英文候选与反查声调等名称稳定的实际设置。
- 候选窗外观把输入框与候选窗预览固定在页面顶部，下方设置单独滚动；字体使用系统字体下拉框，字号、间距、圆角可选也可输入，并开放浅色/深色小狼毫皮肤标识。
- 修复候选预览反复刷新产生叠字的问题；横向、逐行竖向、文字竖排和两种全屏布局均有独立预览，行内显示与输入提示选项也会即时反映。输入习惯、万象设置及主要设置页改用通俗说明，下拉选项右侧显示当前含义。
- 跨方案导入以当前方案为目标，支持白霜与万象双向复制；统计字段明确区分来源总数、目标新增、目标已存在和需确认项。
- 当前方案缺少分组 sidecar 时，从另一已适配方案恢复仍存在于目标词库的分组归属，不删除或改写来源分组文件。
- 分组删除增加“直接删除 / 备份当前词库后删除 / 取消”，只删除分组关系；符号与分组修改统一显式保存。
- 白霜与万象备份按方案隔离；路径编辑改为显式启用、校验后应用，错误路径不会覆盖当前设置。
- 新增低频方案热切换监视和关键写入前强制校验；采集、词库、备份及配置页不会在切换后继续写旧方案。
- 万象更新改为能力优先：版本号不再直接封锁，未登记版本通过结构与设置能力预检后可谨慎更新；在线适配规则可独立更新。增加受二次确认保护的强制更新、与日常备份隔离的恢复快照、部署成功后轮换和部署失败自动恢复，继续排除个人词库、UserDB 与 `*.custom.yaml`。
- 减少启动时部署器递归扫描、空闲页面 20Hz 轮询和按请求创建读取线程；数据引擎与候选预览各自复用单一读取线程。
- 当前源码版本为 v0.9.1；未执行 PyInstaller、未生成发布包。


## v0.8.0 - 2026-08-08

### 词库导入与快速调节

- 词库管理页新增独立“字词快速调节”窗口：用一个精确查找入口查询个人、系统/白霜及万象静态词典；选择结果后在只读的“当前调节项”中确认词条和编码，避免原先字词、编码两个输入入口互相覆盖。系统词条首次调节时安全加入个人词库作为覆盖项，原固定词典保持只读。
- 修复搜索或点击词条时“当前调节项”“实际输入法候选预览”两个分区重新分配高度造成的抖动；两个分区、候选控件及底部状态区均预留固定高度。实际候选按当前 Rime `menu/page_size` 显示（本机为 6 项），不再硬编码为 5 项。
- 快速调节窗口上方搜索已接入系统/白霜与万象索引，不再只过滤个人词库；本机实际搜索“了”可返回 `le`、`liao` 等词典编码。
- 上方搜索改为完整字词/完整规范化编码精确匹配；修复输入 `sm`、`zh` 时误返回 `jism`、`zhujiao` 等子串结果，以及表格重建后旧行高亮与下方预览不一致的问题。
- 精确匹配扩展到程序明确支持的简码：单字母首码、严格简拼、紧凑简拼和混剪简拼；支持 `h` 反查单字候选以及 `wut`、`wti` 反查“物体”，同时仍不会用普通子串包含关系命中无关个人词条。
- 搜索增加短防抖，并在 Windows 输入法预编辑开始时立即清空旧结果，避免原生候选窗覆盖区域显示上一轮词条。
- 快速调节不再以个人/系统/万象静态词典的排序代替实际输入法候选。万象候选由隔离的 Rime 工作目录实时计算，不会以白霜结果或静态词典排序冒充；无法复制的在用 UserDB 会明确提示。
- 快速调节新增“保存”按钮。置顶、上移、下移及系统词条个人覆盖均先写入内存副本，只有点击保存才统一备份、写盘和部署；关闭窗口会提示放弃未保存修改，外部文件发生变化时拒绝覆盖。
- 当前启用方案同时驱动设置页方案信息、紧凑索引和候选预览，避免设置页固定显示白霜而个人词库实际使用万象。
- 主窗口标题栏与状态区显示索引构建文件、字节进度和阶段；快速调节在索引未完成时同步提示。支持取消与重试，取消或失败不会替换旧索引。
- 词典中心支持按当前方案列出原文件名与用途；固定系统词典保持只读，安全的单文件个人词典可暂存增删改后显式保存，并带备份、外部修改冲突检查和失败回滚。
- 建立只读本机词典测试快照，包含活动静态词典、个人短语和可读 UserDB 数据；真实备份集成测试已确认可从万象词典查询“了/le”。发布包不得携带该测试快照。
- 修复重复快速采集已有词条时默认权重覆盖原权重、冲突区调节被后续写入覆盖，以及未明确选择分组时清空原分组的问题。
- 白霜到万象的导入预览现在区分完全重复与同词同码但排序值/格式不同；差异项默认保留万象现有内容并明确报告。
- 候选窗皮肤编辑保持冻结，本轮没有新增或修改相关功能。

## v0.6.4 - 2026-07-16

- 开机自启动改为校验快捷方式目标、`--autostart` 参数与当前程序路径；设置页和托盘勾选状态以实际检测结果为准，移动程序后可识别并修复失效自启项。
