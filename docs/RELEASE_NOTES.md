# 本地发布记录

## v0.8.0 - 2026-08-08

### 词库导入与快速调节

- 词库管理页新增独立“字词快速调节”窗口：用一个精确查找入口查询个人、系统/白霜及万象静态词典；选择结果后在只读的“当前调节项”中确认词条和编码，避免原先字词、编码两个输入入口互相覆盖。系统词条首次调节时安全加入个人词库作为覆盖项，原固定词典保持只读。
- 修复搜索或点击词条时“当前调节项”“实际输入法候选预览”两个分区重新分配高度造成的抖动；两个分区、候选控件及底部状态区均预留固定高度。实际候选按当前 Rime `menu/page_size` 显示（本机为 6 项），不再硬编码为 5 项。
- 快速调节窗口上方搜索已接入系统/白霜与万象索引，不再只过滤个人词库；本机实际搜索“了”可返回 `le`、`liao` 等词典编码。
- 上方搜索改为完整字词/完整规范化编码精确匹配；修复输入 `sm`、`zh` 时误返回 `jism`、`zhujiao` 等子串结果，以及表格重建后旧行高亮与下方预览不一致的问题。
- 精确匹配扩展到程序明确支持的简码：单字母首码、严格简拼、紧凑简拼和混剪简拼；支持 `h` 反查单字候选以及 `wut`、`wti` 反查“物体”，同时仍不会用普通子串包含关系命中无关个人词条。
- 搜索增加短防抖，并在 Windows 输入法预编辑开始时立即清空旧结果，避免原生候选窗覆盖区域显示上一轮词条。
- 快速调节不再以个人/系统/万象静态词典的排序代替实际输入法候选。万象候选由隔离的 Rime 工作目录实时计算，不会以白霜结果或静态词典排序冒充；无法复制的在用 UserDB 会明确提示。
- 快速调节新增“保存”按钮。置顶、上移、下移及系统词条个人覆盖均先写入内存副本，只有点击保存才统一备份、写盘和部署；关闭窗口会提示放弃未保存修改，外部文件发生变化时拒绝覆盖。
- 当前启用方案同时驱动设置页方案信息、紧凑索引和候选预览，避免设置页固定显示白霜而个人词库实际使用万象。
- 主窗口标题栏与状态区显示索引构建文件、字节进度和阶段；快速调节在索引未完成时同步提示。支持取消与重试，取消或失败不会替换旧索引。
- 词典中心支持按当前方案列出原文件名与用途；固定系统词典保持只读，安全的单文件个人词典可暂存增删改后显式保存，并带备份、外部修改冲突检查和失败回滚。
- 建立只读本机词典测试快照，包含活动静态词典、个人短语和可读 UserDB 数据；真实备份集成测试已确认可从万象词典查询“了/le”。发布包不得携带该测试快照。
- 修复重复快速采集已有词条时默认权重覆盖原权重、冲突区调节被后续写入覆盖，以及未明确选择分组时清空原分组的问题。
- 白霜到万象的导入预览现在区分完全重复与同词同码但排序值/格式不同；差异项默认保留万象现有内容并明确报告。
- 候选窗皮肤编辑保持冻结，本轮没有新增或修改相关功能。

### 范围边界

- 旧索引代码与旧索引文件清理保持冻结，不在本轮执行。
- 候选窗皮肤编辑继续冻结；本轮 UI 调整仅针对本工具自身界面。
- 本地发布包未进行商业代码签名，Windows SmartScreen 或杀毒软件仍可能在新版本首次运行时提示。

### 代码维护

- 不改变功能与界面的前提下，统一方案词典根、方案名称、汉字判断和索引进度换算规则，避免多个窗口各自维护副本。
- 设置页词典扫描、个人词典编辑、快速调节搜索与排序、个人词库联合写入和后台部署调度已抽离为独立可测试服务；移除确认无调用的旧同步刷新路径。
- 紧凑索引算法保持原结构，旧索引实现继续按第 6 步冻结要求保留。

### 界面与操作逻辑

- 主导航统一为“词库工作台、词典中心、符号管理、设置”四个工作区；词典中心由设置页弹窗入口提升为稳定工作区。
- 词库工作台重排为页面页头、命令栏、分组与词条工作区、固定保存栏；新增与保存作为主操作，导入、重码、历史和自动分组收纳到“词库工具”。
- 符号管理和设置页采用同一页面标题、内容表面与操作层级；设置仍按常规、词典与文件、备份与恢复、诊断与更新组织。
- 三套主题统一导航、表格、焦点、状态和弹窗视觉；修复水墨主题侧栏选中项背景与文字同色的问题。

### 发布

- 版本升级为 v0.8.0。
- 提供固定名称的单文件版 `RimeConfig.exe` 与目录式 `RimeConfig/`；目录式便携压缩包为 `RimeConfig-portable.zip`。

## v0.6.4 - 2026-07-16

### 自启动与更新

- 开机自启动改为校验快捷方式目标、`--autostart` 参数与当前程序路径；设置页和托盘勾选状态以实际检测结果为准，移动程序后可识别并修复失效自启项。
- 应用内更新按当前包类型选择 GitHub Release 资产：单文件包使用 `RimeConfig.exe`，目录式包使用 `RimeConfig-portable.zip`。
- 目录式更新改为在用户配置目录暂存、验证完整目录、退出后整体交换目录并支持回滚，避免目录包被错误替换成单个 EXE 后发生 DLL 缺失。

### 备份命名与恢复兼容

- 新建备份改为“原文件名_日期时间.bak”规则，例如 `custom_phrase.txt_20260716_153045.bak`；文件从备份目录单独取出时仍可辨认来源。
- 同一秒内重复备份自动追加序号，避免覆盖已有备份。
- 保留对历史短时间戳备份及早期平铺备份的识别、恢复与自动清理兼容性；不自动重命名旧备份。
- 恢复操作仅接受当前受管文件的已识别备份，防止误将其他文件作为恢复来源。

### 目录式发布包

- 修复目录式发布包在移动、更名或更换保存位置后，主题样式与图形界面资源无法正确加载的问题。
- 勾选图标改为 Qt 内置资源，主题样式不再拼接发布目录的绝对路径；复制到中文、空格或特殊字符路径后仍可完整解析。
- 增加 Qt 原生调色板回退，避免目录包在 Windows 外观差异下出现弹窗黑底黑字；托盘统一使用内置多尺寸图标，避免外部图标路径导致黑色图标。
- 复选框与表格勾选改为主题专用的完整“色块加白勾”图标，禁用态使用灰色图标，避免仅显示细小勾选符号。
- 新增冻结程序迁移至中文路径的主题渲染回归测试，覆盖弹窗背景、复选框与样式资源解析。

### 验证

- 自动化测试：`146 passed`；测试环境保留一条 `.pytest_cache` 无写权限警告，不影响程序功能。

## v0.4.3 - 2026-07-14

### 启动、托盘与自启

- Windows 开机自启快捷方式使用专用 `--autostart` 参数：登录后仅托盘常驻，普通双击 EXE 或开始菜单启动仍显示主界面。
- 重复启动不再静默退出；第二个进程会通知已运行实例恢复、置前并聚焦主窗口。
- 托盘图标兼容 Windows 未派发双击事件的情况：延迟处理触发事件，同时保留双击优先恢复窗口。

### 文件与更新可靠性

- 词库、设置、分组和拼音显示 sidecar 改为临时文件写完后原子替换，写入异常时保留旧文件。
- 自动更新下载时校验 GitHub 提供的 SHA-256 摘要；交接程序会等待旧进程退出、保留备份、验证新进程启动，并在失败时恢复旧版本并写入更新日志。

### 启动资源

- 系统词典索引与 Rime 候选预览引擎不再早于主窗口构建；普通启动在首帧后后台预热，开机自启则等用户首次打开界面再启动。

### 验证

- 自动化测试：`122 passed`。
- 已知测试环境提示：`.pytest_cache` 无写权限会产生一条警告，不影响程序功能。

## v0.4.2 - 2026-07-14

### Rime 候选预览

- 采集、单条编辑和多编码编辑窗口均提供独立 Rime 会话的前五候选预览。
- 候选条采用“候选：”与“权重：”双行布局；当前采集文本使用主题强调色标记。
- 系统词典索引支持空格分隔拼音与连续输入编码的规范化匹配，可显示如“完整 / 测试”等系统词典原始权重。
- 候选预览服务在程序启动后后台预热，并在部署成功后自动刷新；空闲后自动退出。
- 候选读取、完成刷新前后预留固定区域，避免采集和编辑窗口内容发生跳动或压缩。

### 说明与验证

- 系统词典提示中的“本工具参考优先级”仅用于整理来源提示，不参与 Rime 实际候选排序。
- 自动化测试：`116 passed`。
- 已知测试环境提示：`.pytest_cache` 无写权限会产生一条警告，不影响程序功能。

## v0.4.1 - 2026-07-13

本版本为本地 Windows 发布包，不上传 GitHub。

### 采集与托盘

- 快速采集窗口会在后台建立系统词典索引；命中同文本同编码时显示来源、翻译器质量与参考权重，可直接采用建议权重。
- 托盘“设置”会显示主窗口并定位设置页；“一键部署”更名为“立即重新部署”，并增加“保存后自动部署”开关。
- Win32 热键采集的剪贴板轮询改用单调时钟并扩展等待窗口，覆盖复制降级时的延迟结果。

### 批量操作与界面稳定性

- 词库批量模式支持行点击、左侧方框和鼠标拖拽连续框选；对勾由程序直接绘制，不依赖外部图标资源。
- 设置页所有复选框改用自绘白色对勾，浅色、深色和水墨主题下均可明确辨认选中状态。
- 修复无界面自动化测试中延时提示框可能访问已销毁页面的问题。

### 验证与产物

- 自动化测试：`116 passed`。
- 已知测试环境提示：`.pytest_cache` 无写权限会产生一条警告，不影响程序功能。

## v0.4.0 - 2026-07-13

本版本为本地 Windows 发布包，不上传 GitHub。

### 词库与编辑

- 支持立即备份、定期备份、保留份数和自动清理旧备份。
- 备份和恢复覆盖受管词库、输入方案、符号表及 `pinyin_display.ini`。
- 采集和编辑窗口支持一个文本维护多个编码，含候选编码的新增、移除和权重调整。
- 英文词条提供小写、大写和原样编码建议；可选择将输出文本转为大写而保持编码小写。
- 多编码删除支持批量勾选，收藏、编辑、删除均保留窗口状态提示与右下角通知。

### 热键、通知与运行

- 修复热键未选中文本时误采集程序工作目录的问题，Win32 与 keyboard 后端均覆盖路径变体。
- 热键采集、自动部署、检查更新和下载更新均移出界面主路径。
- 新增应用内托盘通知补偿，通知展示文本和编码并可手动关闭。
- 新增 Windows 单实例锁，重复启动不会再打开第二个窗口。

### 界面与性能

- 备份设置集中在“备份与恢复”；所有下拉框和数值框均需点击后才响应滚轮。
- 完成浅色、深色和水墨主题的统一语义颜色。
- 词库搜索增加防抖，分组和筛选避免重复整库排序。
- 拼音显示推导加入内存缓存；符号表批量刷新减少布局开销。
- 修正扩展词库统计：英文输入文件 4 个，中英混合用户词库 7 个，不再把脚本或源码计入。
- 日志采用 1MB 轮转并保留 3 份，避免长期运行持续增长。

### 验证与产物

- 自动化测试：`110 passed`。
- 已知测试环境提示：`.pytest_cache` 无写权限会产生一条警告，不影响程序功能。
- 本地可执行文件：`dist/RimeConfig.exe`。
