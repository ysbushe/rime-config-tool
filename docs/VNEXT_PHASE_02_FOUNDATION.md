# VNext 阶段 2：数据与界面基础层

记录日期：2026-08-08

## 已完成

- 数据引擎支持后台索引刷新任务；主进程只负责启动、查询状态和请求取消。
- 构建过程定期检查取消信号；取消或失败会清理临时文件，不替换现有可用索引。
- 精确字词/编码查询支持基于记录游标的有界分页，不一次展开完整候选桶。
- 新增多文件事务写入层：提交前外部修改校验、逐文件原子替换、部分失败整体回滚、异常中断日志恢复。
- 主窗口改为左侧稳定工作区导航；设置页拆分为常规、词典与文件、备份与恢复、诊断与更新四个任务分区。
- 生产环境的快速调节/快速收藏已切换为当前启用方案的 VNext 紧凑索引；万象方案不再同时加载白霜索引。
- 词典中心改由数据引擎按 200 条分页读取，字词与编码搜索统一为精确匹配。
- 个人词库、分组 sidecar 和拼音显示边界已接入联合事务提交；任一文件失败会恢复全部原文件。
- 词库工作台与快速调节统一为“暂存 → 显式保存”；保存失败时磁盘整体回滚，但保留界面内暂存内容供重试或撤销。
- 退出程序、切换 Rime 目录或切换沙盒前增加未保存修改保护，取消操作会恢复原设置且不重建仓储。
- 设置页方案信息改为跟随 Rime 当前启用方案，不再固定读取白霜方案文件。
- 主窗口标题栏、底部状态区与快速调节窗口同步显示索引文件、阶段和字节进度；支持安全取消及失败后重试。
- 万象实际候选改由应用专用隔离目录中的 Rime 会话生成；真实 Rime 用户目录不作为预览写入目录，静态词典结果不再替代真实候选顺序。
- 词典中心按当前方案列出原文件名与用途；固定系统词典只读，安全的单文件个人词典支持暂存编辑、显式保存、备份、外部修改检查与事务回滚。
- 完成首轮维护性瘦身：方案元数据和索引进度规则改为单一来源；设置页词典扫描、个人词典编辑会话、快速调节搜索/排序会话、个人词库联合写入及后台部署协调从窗口类中抽离。
- 设置页原 300 余行的单一界面构建方法按常规、词典与文件、备份、诊断和自启职责拆分；删除已被后台快照替代且确认无调用的同步词典刷新逻辑。
