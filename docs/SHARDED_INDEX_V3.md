# 第三代词典分片索引

记录日期：2026-08-13

## 已确认目标

- 交互查询不再读取大型原始 `.dict.yaml`。
- 查询与索引维护使用独立数据引擎进程，慢构建不得阻塞查询。
- 每个搜索通道最多保留一个执行请求和一个最新等待请求。
- 每个词典源文件对应一个不可变 SQLite 分片；单文件变化只重建该分片。
- `catalog.sqlite` 只保存方案、文件签名、分片名称、顺序和词条数量，并以原子替换切换版本。
- 构建、取消或失败期间继续使用上一代目录和分片。
- 普通启动和万象更新后均等系统空闲再刷新，不延长中文输入不可用时间。

## 当前实现

- 新索引位置：`%LOCALAPPDATA%/RimeConfig/indexes/v3/<scheme>/`。
- 现有 `<scheme>.sqlite` 保留为首次迁移时的只读回退，不自动删除。
- 第三代目录尚未生成或正在构建时，词典中心可从现有紧凑索引按源文件只读分页，不回退扫描原始词典。
- 索引维护数据引擎按需启动，在完成、取消或失败后退出；只读查询引擎不受影响。
- 目录库保留 `catalog.previous.sqlite`；分片清理至少保留当前和上一代引用。
- 词典中心的固定系统词典通过分片索引分页浏览和精确搜索；个人文本词典仍使用现有事务编辑路径。
- 词典依赖只流式读取 YAML 头部，遇到 `...` 即停止。

## 真实万象只读基线

- 源文件：22个，84,172,895字节。
- 词条：2,528,558条。
- 分片索引：193,380,352字节。
- 首次临时构建：198.79秒。
- 常用编码查询中位数：约50～79毫秒。
- 缺失字词查询：65.34毫秒。
- 浏览200条：14.16毫秒。
- 模拟单源变化：重建1个、复用21个分片，处理219字节，0.11秒。

真实 Rime 目录在基线测试中只读；索引写入系统临时目录并在脚本退出后清理。
